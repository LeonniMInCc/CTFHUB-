# 01 · 详细部署步骤

> 目标：在一台**没有 PHP/MySQL/Apache/Docker** 的 Windows 机器上，把天积安全 WEB 靶场平台跑起来。
> 全程不装 Windows 服务、不需要管理员权限，所有文件落在项目目录内。
> 下文以部署目录 `D:\天积` 为例（**路径含中文会踩两个坑**，见 [03-踩坑与排错](03-踩坑与排错.md)）。

最终目录结构：

```
D:\天积\                        ← 靶场源码（git clone 而来）
├─ index.php  api\  range\  config\  ...
└─ .runtime\                    ← 本次新增（运行时，可整体删除）
   ├─ apache\                   Apache 2.4.68（bin\httpd.exe、conf\heasec-httpd.conf）
   ├─ php\                      PHP 7.3.4（php.exe、php.ini、ext\）
   ├─ mariadb\                  MariaDB 10.6.28（bin\mysqld.exe、my-heasec.ini）
   ├─ mariadb-data\             数据库数据文件
   ├─ logs\mariadb-error.log
   ├─ downloads\                离线安装包（可删）
   ├─ tools\                    自检脚本（download.js / db-probe.php / heasec-api.js）
   ├─ start-lab.cmd / .ps1      启动
   └─ stop-lab.cmd / .ps1       停止
```

## 第 0 步：环境体检

先确认机器上到底有什么，避免重复安装或走错路线：

```powershell
foreach ($c in 'git','node','npm','php','python','docker','composer','wsl') {
  $p = Get-Command $c -ErrorAction SilentlyContinue
  "{0} => {1}" -f $c, ($(if($p){$p.Source}else{'MISSING'}))
}
# 端口占用情况（80/8080/3306 都需要空着或自己改）
foreach ($p in 80,8080,3306) { (Get-NetTCPConnection -LocalPort $p -State Listen -ErrorAction SilentlyContinue) ? "port $p 占用" : "port $p 空闲" }
# VC++ 运行库（Apache / PHP 都依赖，Windows 10/11 一般自带）
(Get-Item "$env:SystemRoot\System32\msvcp140.dll").VersionInfo.FileVersion
```

本次实测结果：`git`/`node`/`python` 有，`php`/`docker`/`wsl` 无；8080、3306 均空闲；VC 运行库 14.51.36231.0（满足 Apache VS18 与 PHP VC15）。

> 结论：无法用官方 Docker 方式（没装 Docker，且装 Docker Desktop 需要 WSL2 + 管理员 + 重启），也无法用 PHPStudy（图形安装包 + 管理员）。→ 采用便携三件套。

## 第 1 步：获取源码

```powershell
git clone https://github.com/HeaSec/HeaSecWebLab.git "D:\天积"
git -C D:\天积 log --oneline -1      # 本次为 e019ec9 release: v1.0.4
git -C D:\天积 status --short        # 应为空，保持工作区干净
```

**⚠️ 若报 `schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS`**（本机实测如此）：
这是 Git for Windows 自带的 schannel TLS 后端在该环境下取不到凭据，不必改全局配置，单次指定 OpenSSL 后端即可：

```powershell
git -c http.sslBackend=openssl clone https://github.com/HeaSec/HeaSecWebLab.git "D:\天积"
```

若还配了本地代理，Git 会自动使用（`git config --global http.proxy http://127.0.0.1:10808`）。

## 第 2 步：下载三个组件

| 组件 | 下载地址 | 大小 | SHA256（下载后校验） |
|---|---|---|---|
| Apache 2.4.68 Win64 | `https://www.apachelounge.com/download/VS18/binaries/httpd-2.4.68-260827-Win64-VS18.zip` | 13.9 MB | `A6B7DE9FDCCB28456F5B1F884920FE0B2425AADFCA25C63AE1C0969D43BB355B`（与 Apache Lounge 官方公布值一致） |
| PHP 7.3.4 TS VC15 x64 | `https://windows.php.net/downloads/releases/archives/php-7.3.4-Win32-VC15-x64.zip` | 24.3 MB | `9CBEFEFF4D4C07D7BD3F3830EDEF61DDC9259DCAFF2C6DEE2CB9BFD44B27F1D9` |
| MariaDB 10.6.28 winx64 | `https://mirrors.aliyun.com/mariadb/mariadb-10.6.28/winx64-packages/mariadb-10.6.28-winx64.zip` | 83.8 MB | `A4E5CD01587D1662728F0CF0D8BB3D1AAEDC6861B272CEC18F504AB4BA8B2F72` |

要点：

- **PHP 必须选 TS（线程安全）版**，文件名里带 `Win32-VC15-x64.zip`（TS），不是 `nts`。只有 TS 版才有 `php7apache2_4.dll`，才能被 Apache 以 mod_php 方式加载。
- PHP 7.3.4 是官方 README 指定的版本；用 8.x 会因为语法/函数行为差异导致部分关卡无法利用。
- MariaDB 镜像备选：`archive.mariadb.org`、`mirrors.huaweicloud.com` 均可；**清华源（tuna）该路径返回 403**，别用。
- 下载建议用本目录的 `scripts/download.js`（跟随 302 跳转、支持断点续传、有进度输出）：

```powershell
node scripts\download.js <url> D:\天积\.runtime\downloads\php-7.3.4-Win32-VC15-x64.zip
```

- 校验：

```powershell
Get-FileHash D:\天积\.runtime\downloads\httpd-2.4.68-Win64-VS18.zip -Algorithm SHA256
```

## 第 3 步：解压与目录规划

```powershell
$rt = 'D:\天积\.runtime'
Expand-Archive "$rt\downloads\httpd-2.4.68-Win64-VS18.zip" "$rt\tmp" -Force
Expand-Archive "$rt\downloads\php-7.3.4-Win32-VC15-x64.zip"   "$rt\tmp\php" -Force
Expand-Archive "$rt\downloads\mariadb-10.6.28-winx64.zip"     "$rt\tmp2" -Force
Move-Item "$rt\tmp\Apache24" "$rt\apache"
Move-Item "$rt\tmp\php"      "$rt\php"
Move-Item "$rt\tmp2\mariadb-10.6.28-winx64" "$rt\mariadb"
Remove-Item "$rt\tmp","$rt\tmp2" -Recurse -Force
New-Item -ItemType Directory -Force "$rt\logs" | Out-Null
```

## 第 4 步：配置 PHP

以 `php.ini-development` 为底（保留默认项），再追加官方 `docker/php/zz-heasec.ini` 的等价配置：

```powershell
Copy-Item "$rt\php\php.ini-development" "$rt\php\php.ini" -Force
# 然后把 conf\php-heasec.ini 的内容追加到 php.ini 末尾
```

`conf/php-heasec.ini` 内容（**关键项已注释说明**）：

```ini
; ================= 靶场运行时配置（对齐官方 docker/php/zz-heasec.ini）=================
; ⚠️ 关键：本机部署目录含中文，PHP 7.3 从「中文绝对路径」加载扩展 DLL 会直接崩溃(0xC0000005)，
;    因此这里必须用相对目录，并保证进程工作目录 = 本 PHP 目录（启动脚本已处理）。
extension_dir = "ext"

extension=curl
extension=fileinfo
extension=gd2
extension=mbstring
extension=exif
extension=mysqli
extension=pdo_mysql
extension=pdo_sqlite
extension=sqlite3
extension=openssl
extension=sockets
extension=soap
extension=xmlrpc
extension=xsl
extension=bz2
; ⚠️ 不要写 extension=zip：本构建已静态内置 zip（php -n -m 可见），重复加载会导致启动崩溃

short_open_tag = On
output_buffering = 4096
max_execution_time = 300
max_input_time = 60
memory_limit = 256M
post_max_size = 100M
upload_max_filesize = 100M
max_file_uploads = 20
max_input_vars = 3000
error_reporting = E_ALL & ~E_NOTICE
display_errors = On
display_startup_errors = On
log_errors = On
default_charset = "UTF-8"
date.timezone = Asia/Shanghai
allow_url_fopen = On
allow_url_include = Off
expose_php = On
session.save_handler = files
session.gc_divisor = 1000
mysqli.default_port = 3306
```

验证扩展是否全部加载（**必须在 PHP 目录下执行**）：

```powershell
cd D:\天积\.runtime\php
.\php.exe -c .\php.ini -m | Select-String 'mysqli|pdo_mysql|gd|curl|soap|openssl|sockets|zip'
# 期望看到：bz2 curl exif fileinfo gd mbstring mysqli openssl pdo_mysql pdo_sqlite soap sockets sqlite3 xmlrpc xsl zip
.\php.exe -c .\php.ini -v      # PHP 7.3.4 (cli) ( ZTS MSVC15 )
```

## 第 5 步：配置 Apache（mod_php 方式）

`conf/heasec-httpd.conf`（完整文件在 `conf/` 目录，要点如下）：

```apache
Define SRVROOT "D:/天积/.runtime/apache"
ServerRoot "${SRVROOT}"
Listen 8080                                  # 官方 docker 映射的也是 8080
PidFile "${SRVROOT}/logs/httpd.pid"

# 常规模块（mpm_winnt 为静态编译，无需 LoadModule）
LoadModule access_compat_module modules/mod_access_compat.so
LoadModule authz_core_module    modules/mod_authz_core.so
LoadModule autoindex_module     modules/mod_autoindex.so
LoadModule deflate_module       modules/mod_deflate.so
LoadModule dir_module           modules/mod_dir.so
LoadModule filter_module        modules/mod_filter.so
LoadModule headers_module       modules/mod_headers.so
LoadModule mime_module          modules/mod_mime.so
LoadModule rewrite_module       modules/mod_rewrite.so
LoadModule setenvif_module      modules/mod_setenvif.so
# ...（其余见 conf/heasec-httpd.conf）

# ---- PHP 7.3.4 (mod_php)：注意先 LoadFile 再 LoadModule ----
LoadFile   "D:/天积/.runtime/php/php7ts.dll"
LoadModule php7_module "D:/天积/.runtime/php/php7apache2_4.dll"
<IfModule php7_module>
    PHPIniDir "D:/天积/.runtime/php"
    AddType application/x-httpd-php .php
</IfModule>

DocumentRoot "D:/天积"
<Directory "D:/天积">
    Options FollowSymLinks
    AllowOverride All          # ⚠️ 必须：各靶场目录下的 .htaccess 依赖它
    Require all granted
    DirectoryIndex index.php index.html
</Directory>

<Location />
    Header set Cache-Control "no-store, no-cache, must-revalidate, max-age=0"
    Header set Pragma "no-cache"
    Header set Expires "Thu, 01 Jan 1970 00:00:00 GMT"
</Location>
```

校验语法（**工作目录设为 PHP 目录**，否则扩展加载会失败）：

```powershell
Set-Location D:\天积\.runtime\php
D:\天积\.runtime\apache\bin\httpd.exe -f D:\天积\.runtime\apache\conf\heasec-httpd.conf -t
# 期望输出：Syntax OK
```

## 第 6 步：初始化 MariaDB

一键生成数据目录、设置 root 密码：

```powershell
D:\天积\.runtime\mariadb\bin\mysql_install_db.exe `
  --datadir="D:\天积\.runtime\mariadb-data" --password=root --port=3306
# 期望输出：Running bootstrap / Creating my.ini file / Setting root password / Creation of the database was successful
```

再写一份专用配置 `conf/my-heasec.ini`（对齐 `docker-compose.yml` 的参数）：

```ini
[mysqld]
basedir=D:/天积/.runtime/mariadb
datadir=D:/天积/.runtime/mariadb-data
port=3306
bind-address=127.0.0.1                  # 只监听本机，避免暴露
character-set-server=utf8mb4
collation-server=utf8mb4_general_ci
default-storage-engine=MyISAM           # 官方 compose 指定 MyISAM
max_allowed_packet=16M
lower_case_table_names=1
skip-name-resolve
log-error=D:/天积/.runtime/logs/mariadb-error.log

[client]
port=3306
default-character-set=utf8mb4
plugin-dir=D:/天积/.runtime/mariadb/lib/plugin
```

> ⚠️ **该文件必须存成 ANSI/GBK 编码**（Windows 中文代码页），因为路径含中文而 MariaDB 以 ANSI 读取配置；用 UTF-8 保存会因路径乱码而启动失败。写文件示例：
> ```powershell
> [System.IO.File]::WriteAllText($path, $cfg, [System.Text.Encoding]::GetEncoding(936))
> ```

启动并验证：

```powershell
Start-Process D:\天积\.runtime\mariadb\bin\mysqld.exe `
  -ArgumentList "--defaults-file=`"D:\天积\.runtime\mariadb\my-heasec.ini`"" -WindowStyle Hidden
Start-Sleep 6
D:\天积\.runtime\mariadb\bin\mysql.exe --user=root --password=root --host=127.0.0.1 `
  --execute="SELECT VERSION() v, @@character_set_server cs, @@default_storage_engine e, @@lower_case_table_names l;"
# 期望：10.6.28-MariaDB | utf8mb4 | MyISAM | 1
```

> 小坑：`mysql.exe -h127.0.0.1` 这种短选项在 PowerShell 里会被截断成 `-h127`，**请用长选项 `--host=127.0.0.1`**。

## 第 7 步：启动服务

```powershell
D:\天积\.runtime\start-lab.cmd      # 或 start-lab.ps1
# 输出：[OK] MariaDB 已就绪 (端口 3306) / [OK] Apache 已就绪 (端口 8080)
```

启动脚本做了三件事：端口已占用则跳过、以隐藏窗口方式拉起进程、轮询等待端口就绪（数据库 60s / Apache 30s）。
⚠️ 启动 Apache 时**必须把工作目录设为 `.runtime\php`**（PHP 的 `extension_dir` 是相对路径），脚本已处理。

冒烟测试：

```powershell
curl.exe -s -o NUL -w "%{http_code}`n" http://127.0.0.1:8080/       # 期望 200
```

## 第 8 步：初始化靶场数据库

浏览器打开 <http://localhost:8080/>，首页会自动弹出「初始化数据库」提示，点确认即可。
也可以用接口直接初始化（推荐脚本化，本目录 `tools/heasec-api.js` 即为此用）：

```powershell
# 初始化主库 + 全部子靶场库（约 2 分钟，逐库执行，中途客户端可能超时属正常）
node tools\heasec-api.js /api/heasec/reset_database.php `
  "confirm=YES_RESET_DATABASE&is_initialization=1&reset_learning_status=0&reset_sms_simulator=1"
```

**本次实际结果**：59 个子靶场库中 58 个一次成功，`smsbypass`（短信验证码绕过）因初始化时 `heasec_common` 库尚未建立而失败，补跑一次单库初始化即可：

```powershell
node tools\heasec-api.js /api/heasec/initialize_range.php "range_directory=%2Flogic%2Fbypass_verify%2Fsmsbypass"
# 返回：{"success":true,"message":"靶场数据库初始化成功！"}
```

## 第 10 步：日常启停与卸载

```powershell
D:\天积\.runtime\start-lab.cmd     # 启动
D:\天积\.runtime\stop-lab.cmd      # 停止（httpd -k stop + mysqladmin shutdown，带兜底强杀）
```

- **卸载**：先停止服务，再删除 `D:\天积\.runtime` 整个目录即可——注册表、系统服务、PATH 均未被改动。
- **想省空间**：确认组件包不再需要后，可删除 `.runtime\downloads`（约 120MB）。
- **恢复出厂**：平台首页右上角有「重置数据库」（可勾选是否重置靶场数据 / 学习进度），也可再调一次第 8 步的初始化接口。
- **让 `.runtime` 不进入 git**：在 `D:\天积\.git\info\exclude`（仅本地，不提交）里加一行 `.runtime/`。
