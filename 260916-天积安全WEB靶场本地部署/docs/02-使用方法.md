# 02 · 靶场使用方法

> 部署完成后浏览器打开 **<http://localhost:8080/>** 即可开始学习。
> 平台共 **85 个靶场**，按「WEB 安全基础知识 → 输入验证类漏洞 → 业务逻辑类漏洞 → 综合实战」组织，自动记录学习进度。

---

## 一、访问与账号

- 地址：<http://localhost:8080/>（本机）／`http://<你的IP>:8080/`（需先在防火墙放行 8080 入站）
- **无需注册登录**：平台前台直接使用，学习进度保存在本机数据库中
- 首次访问若提示「初始化数据库」，点确认即可（本机已初始化完成，不会再提示）

## 二、界面导航

| 区域 | 作用 |
|---|---|
| 左侧一级分类 | 4 大分类：WEB 安全基础知识 / 输入验证类漏洞 / 业务逻辑类漏洞 / 综合实战 |

| 靶场页面右上角 | **重置本靶场**、**短信模拟器**（需要手机验证码的关卡） |

## 三、一个靶场的标准做题流程

1. **进入靶场**：从卡片点击进入，例如 `SQL注入练习` → `/range/inputverify/sqli/sqlibase/index.php`。
2. **读题**：页面给出业务场景与目标（部分关卡）与「互动教学模式」提示；除互动模式外，**不提供具体解题步骤**，需自己动手或查资料。
3. **动手测试**：用浏览器或 Burp Suite / 浏览器开发者工具（F12）发请求，观察响应。
4. **提交 / 通关**：多数关卡在页面内提交结果（如获取到的 flag、越权拿到他人数据、上传并执行成功等），平台会记录「已掌握」与星级。
5. **卡住了**：点靶场右上角的**重置按钮**把该靶场恢复到初始状态再试（重置后通关密码等随机数据会变化）。

> 小技巧：每个靶场是**独立会话**（`HEASEC_RANGE_XXXX_SESSION`），互不干扰；因此可以放心地在一个靶场里反复重置、来回折腾，不会影响别的关卡和你的学习进度。

## 四、几个机制说明

### 1. 学习进度与星级

进度存在本机数据库（前缀 `heasec_`，前台库为 `heasec_cms`）中，字段包括 `learning_status`（待学习/学习中/已掌握）、`earned_stars`、`earned_achievements` 等。所有记录都在你自己机器上，不会上传。

### 2. 靶场重置（单个）

靶场页面右上角「重置」：仅重置**当前靶场**的数据与随机值（如通关密码），不影响其他靶场与学习进度。

### 3. 数据库重置（整体）

首页右上角「重置数据库」：

- 可勾选 **重置靶场数据**（所有子靶场库恢复初始）、**重置学习进度**、**重置短信模拟器数据**；
- 底层就是 `POST /api/heasec/reset_database.php`，需要 `confirm=YES_RESET_DATABASE`；
- 重置后需要等它逐库执行（约 2 分钟），页面会自动刷新。

> 也可以命令行触发，便于脚本化（见 `tools/heasec-api.js`）：
> ```powershell
> node tools\heasec-api.js /api/heasec/reset_database.php "confirm=YES_RESET_DATABASE&is_initialization=1&reset_learning_status=0&reset_sms_simulator=1"
> ```

### 4. 短信模拟器

「短信验证码绕过」「密码重置」等关卡需要手机接收验证码。不要真机操作——点靶场右上角的**短信模拟器**，在其中模拟手机端，接收平台下发的验证码，再回到靶场完成验证。相关数据存在 `heasec_common.heasec_sms_simulator` / `heasec_sms_log` / `heasec_sms_message`。

### 5. 互动教学模式

官方说明：除「互动教学模式」外，其他模式不提供具体操作步骤，目的是让你自己查资料、动手实践。遇到完全没有思路的关卡，建议先在「互动教学模式」里熟悉交互方式。

## 六、推荐学习路径

1. **打地基**：HTTP 协议基础（6 关）→ 网站前端代码基础（4 关）→ 服务端语言基础（6 关）
2. **输入验证类**：文件上传（11）→ XSS（9）→ 命令执行（6）→ SQL 注入（11）→ XML/XXE（3）→ 反序列化（3）
3. **业务逻辑类**：绕过验证 / JWT / 身份管理（16）→ 越权访问（5）→ 交易篡改（5）
4. **综合实战**：商城系统综合实战（1），把前面所有思路串起来

每一关的「难度」标签可作为取舍依据：基础 → 进阶 → 拓展 → 实战。

## 八、常见问题

**Q：页面报数据库连接失败？**
先确认 MariaDB 在跑（`Get-Process mysqld`），再核对 `D:\天积\config\config.json` 里的 `host/port/username/password`（默认 `localhost / 3306 / root / root`）。

**Q：某些关卡行为跟别人不一样？**
优先检查 Apache 的 `AllowOverride All` 是否生效——靶场目录里的 `.htaccess` 会影响目录浏览、MIME 类型、POST 体解析（`php_value enable_post_data_reading 0`）等行为。

**Q：能换端口或改成局域网访问吗？**
可以。Web 端口改 `.runtime\apache\conf\heasec-httpd.conf` 的 `Listen`；数据库端口改 `.runtime\mariadb\my-heasec.ini` 的 `port` 并同步 `config\config.json`。**但强烈建议保持仅本机访问**：平台故意包含大量漏洞、前台无登录，还带一键重置数据库按钮。

**Q：学习进度怎么备份？**
备份目录 `.runtime\mariadb-data`（整个数据库）即可；或在 MySQL 里 `mysqldump`。彻底恢复出厂则删除该目录后重跑 `mysql_install_db.exe` 与初始化接口。
